# 📞 contact-manager-cli

Python phone book manager with search, validation & CRUD - Dictionary, Functions, Loops

## 🚀 Features
- Search name by phone number
- Search number by name
- Phone validation (10 digits only)
- Add new contacts

## 🛠️ Tech Stack
- Python Dictionary
- Functions & Loops
- Input Validation

## ▶️ How to run
```bash
python phone_book.py
